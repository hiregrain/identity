# Independent reference model and differential harness

## Objective

A second implementation, written from the contract by someone who has not
read the kernel, that must agree with it byte for byte.

## Scope

- The gap this closes: the layer promised "differential tests against an
  independently-authored reference model" and criterion 1 referenced it, but no
  task created it. Golden vectors cannot substitute. **The vectors are
  generated by the implementation they test**, so a contract misreading
  baked into the generator produces vectors that agree with the bug.
- A TypeScript reference implementation of canonicalization, JWS envelope
  construction, and verification, authored **from `contract/CONTRACT.md`
  alone**. The dispatch instruction is explicit: do not read
  `core/kernel/`. Independence is enforced by how the task is assigned, not
  hoped for. Two implementations by one author share their misreadings and
  agree on being wrong.
- Differential harness: randomized and fuzzed inputs through both
  implementations, comparing output bytes. Any divergence is a failure in
  one of them and a finding either way: the contract is the referee.
- Fuzz corpus committed, so a divergence found once is a regression test
  forever.
- Where the two disagree and the contract is ambiguous, the ambiguity is
  resolved in `contract/CONTRACT.md` as a normative addition (the T1 spike
  produced seven such resolutions; this is the same mechanism).

## Acceptance

- AC (mechanical): the harness runs both implementations over the committed
  corpus plus fresh randomized input with zero divergence.
- AC (mechanical): a deliberately introduced canonicalization bug in either
  implementation is caught by the harness, not just by the vectors.
- AC: every ambiguity the harness surfaced is either resolved in the
  contract or recorded as a known-divergence with reasoning.

## Outside check

Verifier confirms from the task's dispatch record that the reference author
had no kernel access, runs the harness on fresh random input, and plants one
number-formatting bug in each implementation in turn to confirm detection.
